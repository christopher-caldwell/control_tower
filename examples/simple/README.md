# Simple examples

Small workspaces that teach Control Tower's core executable-stage model:

| Workspace | Requirements | Lesson |
| --- | --- | --- |
| [uuid-file](uuid-file/README.md) | Unix shell and built Control Tower binaries | Share the runner's UUID, verify transitions, and reverse accepted stages. |
| [generated-id](generated-id/README.md) | Also Python 3 with standard-library SQLite | Carry an application-generated ID in an explicit JSON handoff. |

Each walkthrough runs a disposable copy. Neither example needs third-party Python
packages, Node, PostgreSQL, or PyCapsule. Return to the [gallery](../README.md).
